# Visual report (pillars)

Scope: `pillar=true` slugs in `content-map.csv`. Images come only from `public/blog/`. No new files were manufactured. Standard (non-pillar) drafts were left alone.

Rule used: add 2-4 markdown images only when a pillar had none or one, and a still would make a mechanism easier to hold. If the draft already had two stills, or one still plus a table that already does the teaching, I left it.

## Received images

### proxies-in-an-antidetect-browser (was 0, now 3)

This was the only pillar with no stills. The page is a stack: room, then line, then geo, then sticky. Three existing files sit on those joints.

- `blog-proxy-map.png` after the room-versus-line section. The map is the exit. The caption says isolation still lives in the folder.
- `blog-timezone-clock.png` after the geo-alignment habit. Clocks are the host leak if the lookup fails.
- `blog-residential-street.png` after sticky versus rotate. One lit window is the login that expects one street.

A fourth still would have repeated the same stack. I stopped at three.

### browser-automation-vs-a-real-profile (was 1, now 3)

- `blog-cookie-jar.png` after "The two jobs." A profile exists to keep a jar. A driver exists to exit.
- `blog-empty-chair.png` before the closing line. A person opens a work room. A test deletes its directory.

The comparison table already names the columns. I did not add a third new still on top of that table.

### multiple-accounts-on-one-pc (was 1, now 2)
