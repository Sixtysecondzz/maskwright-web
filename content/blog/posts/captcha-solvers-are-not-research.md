The commercial query wants a leaderboard. Which solver is cheapest. Which one clears Cloudflare. Which one plugs into Puppeteer. I will not write that table.

A captcha is a stop. The page asked for a person, or it asked you to slow down, or it asked you to prove you were invited. Buying a queue of unsolved puzzles is not research. It is paying someone else to ignore the sign.

## What a captcha is doing

A challenge sits on a path the operator wanted to automate or to flood. Sometimes it is clumsy. Sometimes it punishes honest users. Those are real complaints. They are not a license to outsource the challenge.

Research that is allowed usually never sees a captcha. Official APIs do not put a picture grid in the JSON. Public documentation does not. A slow browser on a public marketing page rarely does. If you are hitting challenges in a loop, the job has already left the research category.

The policy page is [automation ethics we follow](/blog/automation-ethics-we-follow). The architecture page is [browser automation versus a real profile](/blog/browser-automation-vs-a-real-profile).

## Why solvers show up next to antidetect tools

Vendor blogs review solvers because the same buyer wants a hidden collector. The stack is a driver, a residential exit, a timing pack, and a captcha API. We skip each layer as a product feature.

[Keyboard timing packs are theater](/blog/keyboard-timing-packs-are-theater). [Social media automation tools we refuse](/blog/social-media-automation-tools-we-refuse). Scripts stay out of work profiles. [Local scripts stay outside work rooms](/blog/local-scripts-outside-work-rooms).

An agent that "handles" the challenge for you is a solver with a chat box. [Agent browsers versus operator profiles](/blog/agent-browsers-versus-operator-profiles). An MCP path that offers the same is still not a local profile. [MCP is not a local profile](/blog/mcp-is-not-a-local-profile).

| Situation | What I do | Solver |
| --- | --- | --- |
| Official API | Never see a grid | Unnecessary |
| Person in an authorized ads profile | Solve it once, with eyes | Unnecessary |
| Staging site I operate | Whitelist CI, or disable on staging | Unnecessary |
| Collector hitting challenges in a loop | Stop | Not research |

## What 0.1 will not ship

MaskWright 0.1 has no solver hook. We will not add a token field. We will not recommend a worker queue. We will not document how to pause a launch until a third party returns a solution.

Batch start will not retry a challenge across profiles. [Batch launch is not a farm](/blog/batch-launch-is-not-a-farm).

If a work profile shows a captcha to a person who is allowed to be there, the person solves it. That is the only case here. A person, once, in a profile they own.

## What research looks like without a solver

A researcher with a right to the page uses the published path. They accept that some properties will not be machine-readable. They keep a notes file. They do not keep a token ledger.

A QA engineer on a site they operate can disable the challenge in staging, or whitelist the CI egress, or use a test key the security team issued. That is not a solver. That is an invite.

A person in an authorized ads profile who hits a checkpoint completes it once, with their own eyes, and then asks why the profile looks like a driver. Usually a script got too close to the cookies.

## What to do when the sign appears

1. Check whether an official API covers the data.
2. Check whether you are on a property you own.
3. If you are collecting, stop the client and read the terms again.
4. If you are a person in an authorized profile, complete the challenge yourself.
5. If you cannot, do not buy a bypass.

I am not going to name solvers to "warn" you either. A warning list is still a shopping list. If the challenge appeared because a driver arrived, remove the driver. Do not buy a token.

Use [Automation](/blog/automation) for the rest of the cluster. The title is the rule. Captcha solvers are not research, and they are not a MaskWright feature.

## FAQ

### What if I am a real person and the captcha is broken?

Solve it if you can, or use another official path. A broken challenge is still not a reason to wire a third-party solver into a collector.

### Will you add solver support later?

Not in 0.1. The app launches profiles. It does not buy tokens.
